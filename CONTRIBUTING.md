# Contributing to ResearchPilot AI

## Project Overview

ResearchPilot AI is an AI-powered research assistant that helps users analyze research papers, generate structured summaries, identify potential research gaps, and explore project ideas.

## Team Responsibilities

The team uses a modular workflow to organize development and testing.

- **Sanskruti Wadkar — Integration and Documentation:** Repository organization, documentation, and integration checks.
- **Shruti Hagwanepatil — Frontend:** React user interface, application screens, and UI testing.
- **Ishwari Pardeshi — Backend:** Express APIs, server-side processing, and database integration.
- **Nihira Rawade — AI and Testing:** Gemini integration checks, PDF-processing verification, and testing.

These responsibilities describe the proposed division of work and should be updated as each member completes their tasks.

## Git Collaboration Workflow

1. Keep the `main` branch as the shared baseline.
2. Create a separate branch for each task.
3. Make focused, meaningful changes within the assigned responsibility.
4. Commit changes with clear messages.
5. Push the branch to GitHub.
6. Open a pull request for review.
7. Test relevant functionality before merging into `main`.

## Safety Guidelines

- Never commit API keys, private credentials, or `.env` files.
- Keep Firebase service-account credentials private.
- Review changes before merging.
- Test the application after relevant changes.
- Record contributions accurately and do not fabricate commit history.

## Contribution Tracking

Use Git commits and pull requests to document actual changes, reviews, and testing performed by each team member.
